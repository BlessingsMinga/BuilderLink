# BuilderLink Malawi

Milestone 1 project foundation for a Malawi-localized construction marketplace.

## Run locally

1. Install Node.js 20.19+.
2. Run `npm install`.
3. Run `npx expo install --fix` to align Expo-managed packages with the installed SDK.
4. Run `npm start`.

The authentication store is deliberately a local architecture seam only. Firebase authentication, Supabase, and all product data begin in their dedicated future milestones.
